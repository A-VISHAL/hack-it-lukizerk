SHAP XAI Visuals - Installation Guide
=====================================

The SHAP (SHapley Additive exPlanations) feature has been successfully integrated into your iris scanning application!

INSTALLATION STEPS:
-------------------

1. Install SHAP library:
   pip install shap>=0.41.0

2. Or install all requirements:
   pip install -r requirements.txt

3. Restart your Streamlit application:
   python -m streamlit run app.py

WHAT'S NEW:
-----------

✅ SHAP Explainer Integration
   - Computes feature importance for ML predictions
   - Works with Random Forest, Gradient Boosting, and SVM models
   - TreeExplainer for tree-based models (fast)
   - KernelExplainer for SVM (slower but accurate)

✅ Sector Heatmap Visualization
   - Color-coded overlay on iris image
   - Red = High importance (≥0.7)
   - Yellow = Moderate importance (0.4-0.7)
   - Green = Low importance (<0.4)

✅ Feature Importance Bar Chart
   - Top 15 features by SHAP value
   - Red bars = increase health score
   - Blue bars = decrease health score

✅ SHAP Waterfall Plot
   - Shows cumulative feature contributions
   - Visualizes prediction pathway from base value to final score

✅ PDF Report Integration
   - SHAP heatmaps embedded in reports
   - Feature importance tables
   - Plain-language explanations
   - Summary statistics

✅ SHAP Data Persistence
   - Saves SHAP values to JSON files
   - Audit trail for explanations
   - Located in reports/ directory

USAGE:
------

The application will automatically use SHAP when:
1. SHAP library is installed
2. ML models are loaded
3. A prediction is made

If SHAP is not available, the app continues working normally without explanations.

In PDF Reports:

- Heatmap visualizations

TROUBLESHOOTING:
----------------

If SHAP is not working:
1. Check if library is installed: pip list | grep shap
2. Verify ML models are loaded (check models/ directory)
3. Look for SHAP status message in the UI
4. Check console for error messages

The application is designed to work with or without SHAP, so missing SHAP won't break functionality.
