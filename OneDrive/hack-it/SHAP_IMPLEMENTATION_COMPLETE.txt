📚 TECHNICAL DETAILS:

SHAP EXPLAINER TYPES:
  - TreeExplainer: For Random Forest & Gradient Boosting
    * Fast computation (~1-2 seconds)
    * Exact SHAP values
    * Uses tree_path_dependent perturbation

  - KernelExplainer: For SVM models
    * Slower computation (~10-30 seconds)
    * Uses 100 background samples (k-means clustering)
    * Model-agnostic approach

FEATURE EXTRACTION:
  - 63 features total:
    * 15 HSV color features (mean, std, median, q25, q75)
    * 5 GLCM texture features
    * 3 edge features
    * 32 histogram bins
    * 3 structural features
    * 5 intensity features

SECTOR MAPPING ALGORITHM:
  1. Compute absolute SHAP values for all features
  2. Distribute importance equally across 8 sectors
  3. Normalize to [0, 1] range
  4. Map to color codes (red/yellow/green)
