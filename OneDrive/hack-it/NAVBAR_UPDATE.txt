📍 HOW IT WORKS:

1. USER CLICKS A NAVBAR BUTTON
   → Button click triggers page change
   → Session state updates with new page
   → App reruns and displays selected page

2. PAGE NAVIGATION FLOW
   Home → Learn about the app
   Eye Diseases → Browse 26 eye conditions
   Upload → Upload iris images for analysis
   Live Scan → Use camera for real-time capture
   Demo → QR code scanner demo mode
   About → Application information

3. SESSION STATE MANAGEMENT
   - st.session_state.current_page tracks active page
   - st.session_state.navigate_to handles button clicks
   - Automatic cleanup after navigation
